## But
Fin du run : les griffons de *A Gift of Griffons* traversent la zone, des groupes d’ombres les attaquent. Griffons morts, quête ratée.

## Objectif
Tuer chaque embuscade (guerriers, envoûteurs, bêtes de l’ombre) avant qu’elle ne tue les griffons. Le chemin doit déjà être libre ([10 skeles](/fow/duties/10-skeles/)).

## Menaces
- **Envoûteurs** : chaque [Shatter Enchantment](skill:69) retire le dernier enchantement.
- **Bêtes** : [Dark Pact](skill:133) sous 80 % de vie.
- **Guerriers** : [Griffon's Sweep](skill:327) ; [Mirage Cloak](skill:1500) qui se termine sous leur aggro = renversé.

## Solutions
Faire apparaître les bêtes en traversant le groupe, les laisser se poser, compter les envoûteurs dans la boule.
- **0–1 envoûteur** : [Sand Shards](skill:1510), [Mystic Regeneration](skill:1516), [Vow of Strength](skill:1759), [Staggering Force](skill:1498) (couverture, en dernier). ~1 s pour que Staggering revienne, sauter, [Ebon Battle Standard of Honor](skill:2233), se replacer, spiker. Couverture brisée : relancer Staggering avant le spike.
- **2 envoûteurs** : [Mirage Cloak](skill:1500) en seconde couverture. Sauter, laisser Mirage se faire briser **avant** Honor.
- **Avancé** : sans faire apparaître les bêtes. Couverture selon les envoûteurs, entrer, [Death's Charge](skill:952) sur un lanceur au passage sous 80 % : les bêtes lancent Dark Pact sur lui au lieu de vous.

Équipe : [Recall](skill:925) pour écarter des groupes ; T2Way : l’UA ping les griffons, [Fall Back!](skill:1595) accélère Rastigan et les griffons.
