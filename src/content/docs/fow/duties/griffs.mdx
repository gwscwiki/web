Les griffons. Côté VoS, tout dépend de la couverture d’enchantements : compter les envoûteurs dans la boule. Avec 0 ou 1, lancer Shards, Regen, VoS, Staggering dans cet ordre, puis sauter, Honor, se replacer, spiker. Avec 2, lancer Mirage d’abord et le laisser se faire briser avant Honor. En T2Way, l’UA ping pour les griffons.
